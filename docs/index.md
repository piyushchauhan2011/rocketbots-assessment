# Project documentation

The Rocketbots Flow Builder is a client-side Vue 3 application for viewing and editing a persisted workflow graph.

## Guides

- [Quick start](quick-start.md): install, run, build, and reset the application.
- [Architecture](architecture.md): runtime boundaries, data flow, state ownership, and deployment.
- [Design decisions](design-decisions.md): the tradeoffs behind the implementation.
- [Development and quality](development.md): commands, behavior rules, tests, and CI gates.

## API reference

`pnpm docs:build` generates this guide and the TypeDoc API reference from the checked JSDoc contracts in `src/`. Generated files are written to `docs/api/` and are not committed.
